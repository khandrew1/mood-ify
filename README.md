# mood-ify

Welcome to `mood-ify`, a backend system written with Python, FastAPI, and Scikit-learn. Once deployed, it uses a custom ML model and OpenAI models to analyze and generate playlist art for your Spotify playlists.

Check out its sister Next.js front end project: [aesthetic-ify-v2](https://github.com/khandrew1/aesthetic-ify-v2)
